Initial Thoughts:
I note that I cannot sell a stock before I buy obviously. Therefore my initial thought is that for every price I must check if there exists a higher number meaning I can sell for a profit. If I can sell for a profit, I can push a list of integers with the first integer as the profit, the second as the buy day, and the third as the sell day. Then I would loop through the array to find the max and then return the buy and sell day. This would be O(n^3) which is horrible, but just an initial thought. The problem is that the highest profit is not necessarily the lowest stock price. I could loop through every price and for every remaining element keep track of the highest profit and the buy/sell days. Then for the next price I can check if the prospective profit is greater than the current max profit. If it is then I can set the new highest profit and buy/sell days. Initial time complexity of O(n^2) as I am looping through every subsequent number for every number.
