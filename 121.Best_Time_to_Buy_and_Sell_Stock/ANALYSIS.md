My naive attempt was far too slow with O(n^2) resulting in it timing out. The optimal solution uses two pointers to keep track of the max profit. The goal of this problem is for the left pointer to point to the day with the lowest price and the right pointer to point to the day after the lowest price with the highest price. The main question is whether the current transaction is profitable. If it is profitable calculate the profit with 'curr_profit = prices[right] - prices[left]" and compare the current profit with the max profit. If it is not profitable move the left pointer to right which points to the lowest price day. Since it is not profitable, right must point to the lowest price day since right price < left price which should always point to the lowest price. Always move the right pointer by one, since you want to calculate the next profit.
